<section class="copy-section">
<h3>這是什麼</h3>
<p>Floci 是 MIT 授權的本機 AWS 模擬器,供開發、測試與 CI 使用。AWS SDK、CLI、Terraform、CDK 和 OpenTofu 只要指向 http://localhost:4566 就能使用,不需要帳號、auth token 或付費功能閘門。專案提供 Docker 映像、各平台的原生執行檔(Mandrel native image)和 Testcontainers 整合,主打可直接取代 LocalStack。</p>
</section>
<section class="copy-section">
<h3>值得注意的亮點</h3>
<ul>
<li>服務涵蓋廣:S3、SQS、SNS、DynamoDB、EC2、ECS、RDS、IAM、CloudFormation、Cognito、ElastiCache 等,由 Query / JSON / REST 協定控制器分派。</li>
<li>提供 docker compose 與原生執行檔(Linux/macOS/Windows),另有官方 floci CLI 與 awslocal 包裝腳本,上手步驟少。</li>
<li>支援多個 AWS partition(含 cn、us-gov、eusc),request shapes 與 partitions.json 由 botocore 模型腳本產生,貼近真實 AWS 行為。</li>
<li>測試規模大:src/test 下的 Java 測試檔超過 3000 個,另有 compatibility-tests 目錄(含 CDK 等相容性套件)。</li>
<li>CI 完整:有 19 個 workflow,包含 checkstyle、nightly、相容性測試、schema 漂移檢查與 release 自動化,另有 dependabot。</li>
</ul>
</section>
<section class="copy-section">
<h3>適合誰使用</h3>
<ul>
<li>在本機或 CI 取代 LocalStack,跑 AWS SDK 或 IaC(Terraform/CDK/OpenTofu)的整合測試</li>
<li>用 Testcontainers 為服務起一個臨時的 AWS 環境</li>
<li>離線或免雲端帳號時開發 AWS 應用,例如 S3、SQS、DynamoDB 的流程</li>
<li>驗證多 partition(中國、GovCloud)下的 ARN 與端點行為</li>
</ul>
