<section class="copy-section">
<h3>這是什麼</h3>
<p>Tailcat 是用 Go 撰寫的 CLI 與函式庫,把 Tailscale 的開源元件(userspace WireGuard、magicsock、gVisor netstack、DERP)重組成類似 netcat 的點對點工具。伺服端啟動後會印出一串短位址(tc…),客戶端用該位址連線;連線中繼資料改由帶外方式交換,先經 DERP 引導,再嘗試 NAT 打洞升級為直連。解決的是在不註冊帳號、不改路由、不需管理員權限下,讓兩台機器安全互連的問題。</p>
</section>
<section class="copy-section">
<h3>值得注意的亮點</h3>
<ul>
<li>功能涵蓋 stdin/stdout 管線、serve 連接埠轉發、forward、browse、內建 SSH 伺服器(支援 authorized_keys 與 GitHub 公鑰)、SFTP 檔案分享/收件匣、iperf 式 perf、SOCKS5、exit-node</li>
<li>純 userspace 運作,不需 root、不動路由與 DNS;預設啟用 WireGuard 預共享金鑰,具後量子保護,位址本身即為秘密憑證</li>
<li>可自架 DERP 中繼,也提供 Go 函式庫(TCP/UDP)、libtailcat C 共享函式庫與 WebAssembly 瀏覽器版範例</li>
<li>檔案服務以 Go 的 os.Root 限制路徑,收件匣為唯寫並由伺服端決定檔名,SECURITY.md 列出已修復的外部回報</li>
<li>跨平台 CI(Linux/macOS/Windows、BSD 交叉編譯、無頭瀏覽器測試),Actions 以 commit SHA 固定版本</li>
</ul>
</section>
<section class="copy-section">
<h3>適合誰使用</h3>
<ul>
<li>在 NAT 後的兩台機器間臨時傳檔、傳文字或管線資料,不必設定 VPN</li>
<li>不開放入站連接埠,以 DNS TXT 搭配 --allow 白名單提供受保護的 SSH 存取</li>
<li>把內網服務(如 adb、資料庫、網頁)暫時轉發到本機,用於除錯或遠端協作</li>
<li>在 Go 程式中嵌入點對點加密通道,或用 perf 量測兩端直連的吞吐量與延遲</li>
</ul>

<h3>安全觀察</h3>
<div class="risk-label risk-label--low">低風險</div>
<ul class="risk-findings">
<li>功能本身具備高權限能力:`serve no-auth-ssh` 不需客戶端驗證,任何取得位址者即可取得執行該程序之使用者的 shell;`serve exec` 會對每個連線執行指令;`serve exit-node` 可讓客戶端存取伺服端所在網路。README 與 SECURITY.md 均有明確警告,使用者應僅在信任對象間分享位址。</li>
<li>tailcat 位址是帶有預共享金鑰的承載憑證;若發佈於公開 DNS TXT,需搭配 --allow 或 --ssh-authorized-keys,否則任何人皆可連線。使用 genkey 儲存金鑰後,先前分享過位址的人仍可連到後續啟動的伺服器。</li>
<li>預設的 DERP 對應表來自 https://tailcat.dev/derpmap.json,並使用 Tailscale 營運的公用中繼(有速率限制,不保證可用性);`--ssh-authorized-keys=user@github` 會從 github.com 擷取公鑰。</li>
<li>SECURITY.md 自述威脅模型原本以「同一人操作兩端」為前提,尚未針對互不信任的雙方完整強化,且 API 與線路格式可能變動。</li>
<li>文件與建置腳本中未發現 curl|bash、iwr|iex 等安裝即執行外部內容的模式;Makefile 僅有 go mod tidy;未見混淆程式碼或內嵌的長 base64 載荷;依賴皆為 Tailscale 官方模組與知名 Go 套件。</li>
