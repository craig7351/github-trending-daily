<h3>這是什麼</h3>
<p>Munder Difflin 是一個本地優先的多代理人(multi-agent)協調框架,將 Claude Code、Antigravity(Gemini)、Codex、Grok、Kimi、Qwen 等終端機 CLI 各自包裝成一個 node-pty 程序,並以 Pixi.js 繪製成 2D 辦公室裡走動的角色。核心是磁碟上的「hive」(單一 git 倉庫、逐代理人 mailbox、共享黑板、事件日誌),由一個 GOD 協調代理人負責分派任務、路由訊息,並在涉及花費、破壞性操作或範疇變更時把決策升級給人類核准。</p>
</section>
<section class="copy-section">
<h3>值得注意的亮點</h3>
<ul>
<li>單一 committer 設計:只有 harness 本身會對 hive git 倉庫下 git 指令,代理人只寫檔案,避免多代理人同時操作導致 index.lock 損毀</li>
<li>內建 circuit breaker(steer to constrain to stop)與人類核准佇列,對失控循環、爆量錯誤或超支的代理人自動降級處置</li>
<li>write-only 的 secret broker:代理人只拿到一次性 capability token,實際金鑰只在主行程內解密注入,絕不落地渲染層</li>
<li>支援 10 種代理人引擎、BYOK 金鑰與本地 LLM(Ollama/LM Studio/vLLM),並附內建 Monaco IDE 與 git 分支比較介面</li>
<li>38 支 node:test 單元測試涵蓋終端自動化、hive 路由、Windows cmd shim 等邊界情境,CI 對 macOS 做型別檢查與建置</li>
</ul>
</section>
<section class="copy-section">
<h3>適合誰使用</h3>
<ul>
<li>想讓多個 Claude Code / Codex 等 CLI 代理人在同一台機器上並行工作、互相傳訊息並共享記憶的個人或小型團隊</li>
