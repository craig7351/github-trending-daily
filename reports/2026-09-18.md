<section class="copy-section">
<h3>這是什麼</h3>
<p>BrowserSkill 是 Tencent 開源的瀏覽器自動化工具,由 Rust 寫成的 bsk CLI/daemon 與瀏覽器擴充套件組成,讓 Cursor、Claude Code、Codex 等任何能呼叫 shell 的 AI Agent 借用使用者已登入的瀏覽器分頁執行任務,而不需要另外準備測試帳號或啟動無痕視窗。核心設計是「借用-歸還」機制與內建 human-in-loop:遇到驗證碼、登入或需要人工確認的步驟時,Agent 可請求使用者接手,完成後再繼續。</p>
</section>
<section class="copy-section">
<h3>值得注意的亮點</h3>
<ul>
<li>採用 Cargo + pnpm 混合 monorepo,CLI/daemon 用 Rust 撰寫、擴充套件用 TypeScript + React + WXT 框架</li>
<li>borrow/return 分頁機制搭配可設定的「借用前確認」與「允許人工協助請求」開關,並有協定版本相容性設計(1.0–1.3)</li>
<li>CI 工作流涵蓋 Rust fmt/clippy/test、Windows daemon 與安裝程式測試、前端 lint/typecheck/build,測試檔案數量龐大(僅 bsk-cli 就有 30 多個整合測試)</li>
<li>額外提供 DeepSeek Harness 專用外掛(npm 套件),以及 evals/browser 目錄做跨 Agent 的瀏覽器能力基準測試</li>
<li>install.sh / install.ps1 從 GitHub Releases 下載二進位檔並以 sha256 檢查碼驗證後才安裝,而非直接執行遠端腳本內容</li>
</ul>
</section>
<section class="copy-section">
<h3>適合誰使用</h3>
<ul>
<li>讓程式碼助理類 Agent(Cursor、Claude Code、Codex 等)在測試網站或內部系統時直接沿用你目前登入的帳號狀態,不用另建測試帳號</li>
<li>需要人工介入處理登入、驗證碼等步驟的半自動化瀏覽器任務流程</li>
<li>透過 DeepSeek Harness 或其他 shell-capable agent 建置瀏覽器操作技能(skill)</li>
<li>評估/比較不同 Agent 框架在瀏覽器操作能力上的表現(evals/browser)</li>
</ul>
