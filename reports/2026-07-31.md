<section class="copy-section">
<h3>這是什麼</h3>
<p>chrome-devtools-mcp 是 Google Chrome DevTools 團隊維護的 Model Context Protocol 伺服器,透過 Puppeteer 讓 Claude、Cursor、Copilot 等程式碼代理人能自動化瀏覽器操作、擷取效能追蹤、分析網路請求與 Console 訊息、進行記憶體快照比對等工作。目標是把 DevTools 的除錯與效能分析能力開放給 AI agent,用於可靠的網頁自動化與深度除錯。</p>
</section>
<section class="copy-section">
<h3>值得注意的亮點</h3>
<ul>
<li>涵蓋輸入自動化、導覽、效能追蹤、網路、記憶體快照、擴充功能除錯等 40+ 種工具,並支援 slim 模式精簡為 3 個核心工具</li>
<li>官方由 Google LLC 開發維護,底層整合 Puppeteer 與 chrome-devtools-frontend、Lighthouse</li>
<li>支援連線既有 Chrome 實例(remote debugging / autoConnect)與多代理並行的 pageId 路由</li>
<li>測試涵蓋非常完整,含 60+ 單元測試檔與獨立 e2e 測試,CI 在 Ubuntu/Windows/macOS 與多個 Node 版本上跑測試</li>
<li>文件齊全,提供近 20 種 MCP 客戶端(Claude Code、Cursor、VS Code、Gemini CLI 等)的安裝說明與疑難排解指南</li>
</ul>
</section>
<section class="copy-section">
<h3>適合誰使用</h3>
<ul>
<li>讓 AI coding agent 在開發流程中自動開啟網頁、操作元件並驗證修改結果</li>
<li>擷取效能追蹤(trace)並分析 Core Web Vitals 相關的效能瓶頸</li>
<li>透過 Console 訊息與網路請求列表協助除錯前端問題</li>
<li>以記憶體快照比較工具排查瀏覽器端記憶體洩漏</li>
