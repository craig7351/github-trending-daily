<section class="copy-section">
<h3>這是什麼</h3>
<p>agent-desktop 是一個 CLI 加 C 函式庫(FFI)。snapshot 指令會回傳 JSON,其中每個可操作元素都有一個 ref,agent 以 ref 執行 click、type 等動作,再重新 snapshot 驗證,全程不需要比對像素。預設以 headless 方式透過無障礙 API 操作,不移動滑鼠也不搶焦點。專案內建 60 個指令名稱,並附有給 agent 使用的 skills 文件。</p>
</section>
<section class="copy-section">
<h3>值得注意的亮點</h3>
<ul>
<li>以無障礙樹加 ref 取代截圖像素比對,輸出結構化 JSON,對 LLM 友善且 token 成本較低。</li>
<li>支援 macOS、Windows、Linux(AT-SPI)三平台,並提供 libagent_desktop_ffi 供 Python 等語言直接呼叫。</li>
<li>ref 綁定 snapshot,UI 變動時回傳 STALE_REF 或 AMBIGUOUS_TARGET 等結構化錯誤與重試建議,適合 agent 自我修正。</li>
<li>二進位檔內建版本對應的 skills 文件(skills get desktop),並可透過 npx skills 安裝到 agent harness。</li>
<li>工程治理完整:CI 含 CodeQL、supply-chain、gitleaks、跨平台 E2E,並有架構檢查與敏感資訊遮蔽的檢查腳本。</li>
</ul>
</section>
<section class="copy-section">
<h3>適合誰使用</h3>
<ul>
<li>讓 Claude Code 或其他 agent 操作沒有 API 的桌面軟體,例如 Finder、Slack 或內部 GUI 工具。</li>
<li>建立跨平台的桌面 UI 自動化與回歸測試流程,並以 JSON 輸出串接 agent。</li>
<li>在自製 agent 中透過 FFI 以行程內方式嵌入桌面操控能力。</li>
</ul>
</section>

<section class="copy-section">
<h3>值得注意的亮點</h3>

<li>`wt list --full` 顯示每個分支的 CI 狀態與 AI 摘要;`wt switch pr:123` 可直接跳到 PR 分支</li>
