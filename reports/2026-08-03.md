<p class="repo-head__summary">以 DeepSeek 為核心設計、針對 prompt-cache 穩定性優化的終端機 AI 編碼代理人,單一 Go 靜態執行檔。</p>

<div class="repo-body">
<div class="repo-copy">
<section class="copy-section">
<h3>這是什麼</h3>
<p>Reasonix 是一個 config 與 plugin 驅動的終端機 AI 編碼代理人,核心賣點是圍繞 DeepSeek 的 prefix-cache 特性做工程優化(穩定的上下文前綴、cache-aware 的壓縮/裁剪機制),藉此在長時間 session 中大幅降低 token 成本。專案提供 CLI/TUI、桌面 App(Wails)與 VS Code 擴充三種使用形式,底層共用同一個本地 Reasonix engine,並支援任何 OpenAI 相容端點而非綁死單一供應商。</p>
</section>
<section class="copy-section">
<h3>值得注意的亮點</h3>
<ul>
<li>圍繞 DeepSeek prefix-cache 穩定性做架構設計,包含 stale tool output 裁剪、compaction 前的摘要凍結機制,並在 CI 中跑 TestCacheHit* 作為 cache 命中率的回歸守門</li>
<li>工具執行採 OS 層級沙箱隔離(macOS Seatbelt、Linux bubblewrap),寫入僅限白名單目錄、可選擇封鎖網路存取,屬於權限規則之外的強制執行層</li>
<li>外部工具以 stdio JSON-RPC 子行程執行且相容 MCP,內建工具編譯期自行註冊,架構上避免硬編 model/tool</li>
<li>CI/發版流程非常成熟:gofmt/vet/race/golangci-lint/govulncheck/coverage 齊全,發版另有 orchestration guard 與核准環境雙重把關</li>
<li>同時提供 CLI、桌面應用與 VS Code 擴充,三者共用同一顆本地 engine,而非各自重工</li>
</ul>
</section>
<section class="copy-section">
<h3>適合誰使用</h3>
<ul>
<li>在終端機中長時間、多輪次地讓 AI 代理人執行編碼任務,同時想壓低 DeepSeek API 的 token 成本</li>
<li>需要一個不綁死特定模型供應商、可切換 OpenAI 相容端點的編碼代理人框架</li>
<li>想透過 MCP 相容的外部工具插件擴充代理人能力,而非被限制在內建工具集合</li>
<li>在 VS Code 內以 ACP 協定整合本地代理人進行對話式編輯與工具呼叫核准</li>
</ul>
</section>

<li>2026/07 新增 Kimi K3(2.8T 參數)支援,採用逐專家(per-expert)串流而非整層載入,實測單卡 3.72GB 即可運行</li>
<li>支援 4bit/8bit 區塊量化進一步加速 3 倍,也支援 FP8、compressed-tensors 等新式量化格式的相容處理</li>
<li>程式碼中對每個相容性補丁(如 transformers 5.0 API 搬遷、attention 實作 fallback、tied embedding 處理)都寫了清楚的成因註解,顯示維護者對邊界情況掌握度高</li>
<li>近一年內持續有版本更新跟進最新模型(Qwen3、Llama4、DeepSeek-V3 等),反應速度快</li>
</ul>
</section>
<section class="copy-section">
<h3>適合誰使用</h3>
<ul>
<li>個人開發者或研究者想在消費級單張 GPU(甚至 MacBook)上跑超大型開源模型做實驗或推論,不想花錢租多卡伺服器</li>
<li>需要快速嘗試/評測剛發布的旗艦開源模型(如新版 Qwen、DeepSeek、Kimi)但硬體資源有限的場景</li>
