</div>
<p class="repo-head__summary">用 Rust 打造的自架伺服器,把 git 版控的 Markdown wiki 變成可跨 AI coding agent(Claude Code、Codex、Cursor 等)共享的長期記憶與交接系統。</p>
<div class="repo-meta">
<span class="pill">Rust</span>
<span class="pill">累積 7,677 stars</span>
<span class="pill pill--blue">今日 +167</span>

<div class="repo-body">
<div class="repo-copy">
<section class="copy-section">
<h3>這是什麼</h3>
<p>ai-memory 解決的問題是:各家 AI coding CLI(Claude Code、Codex、Cursor…)各自有獨立、無法跨工具延續的記憶功能。它透過 lifecycle hooks 靜默擷取 prompt、工具呼叫與 session 邊界,於 session 結束時整理成可讀的 Markdown wiki 頁面,並提供全文/實體/圖譜(可選向量)融合檢索,讓你中途從 Claude Code 切到 Codex 時能拿到明確的 handoff(交接紀錄)。預設零 LLM 呼叫也能運作,資料以 git 版控的純文字檔為真實來源,並支援多人、多機器共用一台伺服器。</p>
</section>
<section class="copy-section">
<h3>值得注意的亮點</h3>
<ul>
<li>一個 Rust 二進位檔同時提供 MCP/HTTP 伺服器,支援 20+ 種 agent 整合(hooks + MCP),且用 CI 保證支援矩陣不失真</li>
<li>記憶來源是 git 版控的 Markdown wiki,資料庫只是可重建的衍生索引,不會被綁在專屬向量庫裡</li>
<li>跨 agent 的 handoff 協定是「型別化、單一擁有者、只能被 claim 一次」的正式協定,而非口頭約定</li>
<li>密碼雜湊用 Argon2id + 專屬 KDF semaphore 限流,且對不存在使用者做 dummy verify 以防時序攻擊,安全細節做得相當到位</li>
<li>CI 涵蓋 fmt/clippy/多平台測試/cargo-audit/cargo-deny/gitleaks 秘密掃描,外加對 4 種不同 awk 實作的 shell hook 測試矩陣</li>
</ul>
</section>
<section class="copy-section">
<h3>適合誰使用</h3>
<ul>
<li>個人在多台機器(桌機、筆電)或多個 AI coding CLI 之間切換時,希望專案脈絡、失敗嘗試與待辦問題能無縫接續</li>
<li>團隊共用一台記憶伺服器,讓不同成員的 agent session 學到的知識彼此可見,同時保留個人 handoff 隱私</li>
<li>不想依賴雲端記憶 API、希望資料以純文字 Markdown 形式留在自己掌控的機器或 git repo 中</li>
</ul>
</section>
