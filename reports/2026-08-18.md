<section class="copy-section">
<h3>值得注意的亮點</h3>
<ul>
<li>四層嚴格分層架構(renderer → app core → engine adapter → aria2),CI 強制檢查跨層相依邊界,為未來可能的 Rust 重寫預留路徑</li>

<li>Docker Server 映像採非 root 使用者執行、生產依賴安裝時加上 --ignore-scripts、GitHub Actions 皆使用 pinned commit SHA 而非浮動版本標籤</li>
