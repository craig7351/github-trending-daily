<h3>這是什麼</h3>
<p>Superpowers 是一套以 Markdown 技能(SKILL.md)為核心的代理開發流程。工作階段啟動時,它會用 SessionStart hook 注入 using-superpowers 技能,讓代理在寫程式前依序進行需求釐清、設計、計畫、子代理執行、TDD 與程式碼審查。專案提供十多種代理平台的外掛清單與安裝方式,目的是讓代理自主工作較長時間,又不偏離計畫。</p>
</section>
<section class="copy-section">
<h3>值得注意的亮點</h3>
<ul>
<li>完整的工作流程:brainstorming → git worktree → writing-plans → subagent-driven-development → TDD → code review → 收尾分支</li>
<li>同一份技能可用於 Claude Code、Codex、Cursor、Gemini CLI、Copilot CLI、OpenCode、Pi、Hermes、Muse 等十多種平台,各平台有獨立的外掛 manifest</li>
<li>技能內容嚴謹,例如 TDD 技能明訂「沒有先失敗的測試就不能寫正式程式碼」,並附有反合理化的約束</li>
<li>內建 diagnosing-superpowers 技能,可讀取工作階段紀錄、找出技能誤觸發或沒觸發的原因,並匯出已去識別化的 bug 回報</li>
<li>MIT 授權,有 docs/superpowers 下大量的設計規格與實作計畫,等於用自己的方法論開發自己</li>
</ul>
</section>

<li>團隊想在多種程式代理之間統一開發流程與紀律(TDD、驗證、審查)</li>
