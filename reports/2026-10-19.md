<section class="copy-section">
<h3>這是什麼</h3>
<p>ComfyUI 是以 Python/PyTorch 實作的 AI 內容生成引擎,提供節點圖(graph/nodes)介面、HTTP/WebSocket API 與後端執行器。它原生支援 SD、SDXL、Flux、Wan、LTX 等大量開源模型,並以非同步權重串流、智慧 VRAM/RAM 管理與量化支援,讓大型模型能在 4GB VRAM 等低階硬體上運行。可透過桌面應用、可攜版或手動安裝使用,也能搭配自訂節點擴充。</p>

<section class="copy-section">

<li>非同步權重串流、部分圖重新執行與快取機制,可在低 VRAM 環境運行大型模型</li>
<li>完整 API 與自訂節點生態,可嵌入生產流程;另有 App Mode 將複雜工作流包成簡易 UI</li>
<li>支援 NVIDIA、AMD、Intel、Apple Silicon、Ascend 等多種硬體,以及 Windows/Linux/macOS</li>
<li>工程化程度高:數十個 GitHub Actions 工作流、alembic 資料庫遷移、OpenAPI lint 與 CLA 流程</li>
</ul>
</section>

<li>將生成式 AI 工作流透過 API 整合進產品或自動化管線</li>
<li>研究與測試新開源擴散模型,或開發自訂節點與擴充</li>

<p class="repo-head__summary">Jasna 是 GPU 加速的影片/圖片馬賽克還原工具,提供 GUI 與 CLI,模型包含免費的 BasicVSR++ 與支持者專用的 LTX 擴散模型。</p>

<div class="repo-body">
<div class="repo-copy">
<section class="copy-section">
<h3>這是什麼</h3>
<p>Jasna 以 Python 實作,整條流程(解碼、偵測、追蹤、還原、混合、編碼)都在 GPU 上跑,支援 NVIDIA(NVDEC/NVENC/TensorRT)與實驗性的 AMD(ROCm/AMF)。偵測使用 rfdetr,還原使用 BasicVSR++,另有 LTX 擴散模型與 UNet 4x、SD 1.5 等付費模型。專案受 Lada 啟發,README 的基準測試稱在 RTX 5090 上比 Lada 快約 3.4–4.7 倍。</p>
</section>
<section class="copy-section">
<h3>值得注意的亮點</h3>
<ul>
<li>整條處理管線都在 GPU 上執行,README 的基準測試顯示比 Lada 快約 3.4–4.7 倍</li>
<li>同時提供 GUI(Segment Editor、Video Player、佇列、預設組)與 CLI,支援 VR180 和靜態圖片</li>
<li>提供 BasicVSR++(免費)與 LTX 擴散模型(支持者專用,僅 NVIDIA),並附有 LTX 的 CUDA/C++ 原生核心與 INT8 attention(SageAttention 衍生)</li>
<li>repo 內含大量 benchmarks 報告(CSV/MD)、多語系文件(英/日/中)與完整第三方授權說明</li>
<li>tests/ 下有 184 個以上測試檔,涵蓋 GUI、LTX、混合、追蹤等模組</li>
</ul>
</section>
<section class="copy-section">
<h3>適合誰使用</h3>
<ul>
<li>在自有 NVIDIA/AMD GPU 上批次還原影片或圖片中的馬賽克區域</li>
<li>研究 GPU 端到端影片處理管線(NVDEC → TensorRT → NVENC)的實作與效能調校</li>
<li>參考 LTX 擴散模型的 INT8 量化與 Triton/CUDA 核心優化</li>
<li>在雲端租用 GPU(RunPod、Vast)上做影片修復</li>
</ul>
</section>

<h3>安全觀察</h3>
<div class="risk-label risk-label--low">低風險</div>
<ul class="risk-findings">

<li>官方 release 為預編譯執行檔(Nuitka 打包),使用者需自行信任下載來源;README 指出應只從 GitHub 下載,並提醒第三方販售的修改檔可能含隱藏程式碼。</li>
<li>啟用支持者授權碼時需連網(Activate online),啟用後可離線運作;一組授權碼最多綁定 3 台電腦,並以主機板識別碼等硬體資訊判定。</li>
<li>首次執行會依 GPU 編譯 TensorRT 引擎並下載模型權重,使用者應留意下載來源與磁碟空間。</li>
<li>專案依賴含固定版本的 GPU 套件與 Codeberg 上的 VALI 分支(vali fork wheel),建置時需另外取得;repo 內有 assets/test_clip 測試影片(mp4)等少量二進位檔,屬測試素材。</li>
<li>pyproject.toml 無 postinstall 類生命週期腳本,未發現 curl|bash 安裝模式、混淆程式碼或內嵌 base64 載荷。</li>
<li>工具用途為還原影片中的馬賽克,使用者需自行留意內容來源的版權與當地法規。</li>
</ul>
