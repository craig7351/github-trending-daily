<section class="copy-section">
<h3>這是什麼</h3>
<p>Agent Reach 是 Python CLI,把各平台背後的第三方工具(yt-dlp、bilibili-cli、OpenCLI、CloakBrowser 等)裝好並統一成 `agent-reach &lt;渠道&gt; &lt;動作&gt;` 介面,輸出 JSON 給 Claude Code、Cursor 等 Agent 使用。它補足 Agent 內建搜尋與網頁讀取碰不到的部分,包括需登入的平台、影片字幕與語音轉文字、中文平台,以及結構化資料。需要登入的渠道會使用專用瀏覽器,並從使用者 Chrome 複製該網站的登入狀態。</p>
</section>
<section class="copy-section">
<h3>值得注意的亮點</h3>
<ul>
<li>統一的 `agent-reach &lt;渠道&gt; &lt;動作&gt;` 介面,另有 `read &lt;URL&gt;` 依網址自動選渠道,涵蓋約 14 個渠道,分為預設、可選、實驗三級。</li>
<li>第三方工具安裝在 ~/.agent-reach/tools/ 下的私有 venv 或 npm prefix,不污染使用者 PATH,版本並鎖定(例如 yt-dlp==2026.8.19、boss-agent-cli 指向特定 commit)。</li>
<li>內附 Agent 技能文件(SKILL.md、capabilities、sessions 等),安裝方式是請 Agent 讀取 docs/install.md,由 Agent 自行完成設定。</li>
<li>tests/ 有約 28 個測試檔,涵蓋 URL 安全性、憑證清除、私有檔案寫入、各渠道契約等,並有 pytest 與 release 兩條 CI workflow。</li>
<li>中文平台(B站、小紅書、雪球、V2EX、小宇宙)支援完整,對台灣使用者有實用價值。</li>
</ul>
</section>
<section class="copy-section">
<h3>適合誰使用</h3>
<ul>
<li>讓 Claude Code 或 Cursor 等 Agent 搜尋 Reddit、X、小紅書並讀取貼文與留言</li>
<li>擷取 YouTube 與 B站字幕,或將 YouTube 與小宇宙播客轉成文字</li>
<li>在 Agent 工作流程中讀取 GitHub issue/PR、V2EX 討論與雪球行情等結構化資料</li>
<li>蒐集中文社群輿情與職缺資訊</li>
