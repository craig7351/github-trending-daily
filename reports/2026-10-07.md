<section class="copy-section">
<h3>這是什麼</h3>
<p>DeepGEMM 是 DeepSeek 推出的統一 CUDA 核心庫,針對 NVIDIA SM90/SM100 GPU 提供 FP8、FP4、BF16 GEMM、分組 GEMM(contiguous/masked)、融合 EP 通訊的 Mega MoE、V3.2 lightning indexer 的 MQA logits 與 HyperConnection 等核心。所有 kernel 透過 DeepJIT 於執行期編譯,安裝時不需 CUDA 編譯,程式碼精簡,也適合作為學習 GPU kernel 優化的教材。</p>
</section>
<section class="copy-section">
<h3>值得注意的亮點</h3>
<ul>
<li>涵蓋 FP8/FP4/BF16 GEMM、分組 GEMM、Mega MoE(融合 dispatch、兩層線性、SwiGLU、combine 並重疊 NVLink 通訊)與 MQA indexer 等 LLM 核心運算</li>
<li>同時支援 Hopper (SM90) 與 Blackwell (SM100),含 UE8M0 打包 scaling factor、PDL、locality domain 等特性</li>
<li>以 DeepJIT 於執行期編譯 kernel,提供豐富的 DG_JIT_* 環境變數用於除錯、PTX/SASS dump 與快取控制</li>
<li>不重度依賴 CUTLASS 模板,程式結構清晰,適合閱讀學習 GPU kernel 優化</li>
<li>更新頻繁(README 記錄至 2026.09.30),另有 Ascend 版本與完整 tests 目錄</li>
</ul>
</section>
<section class="copy-section">
<h3>適合誰使用</h3>
<ul>
<li>在 H100/H800/B200 上部署 DeepSeek V3/V3.2 類模型的推論或訓練,取得高效 FP8/FP4 GEMM</li>
<li>MoE 模型的專家並行(EP)融合 kernel 與通訊重疊研究與整合</li>
<li>學習與參考 Hopper/Blackwell 的 TMA、WGMMA、tcgen05 等 kernel 實作</li>
<li>作為自研推論引擎的底層算子來源</li>
</ul>
