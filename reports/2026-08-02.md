<section class="copy-section">
<h3>這是什麼</h3>
<p>gh-stack 是 GitHub 官方維護的 gh CLI 擴充套件,協助開發者將一個大改動拆成多個彼此依賴、逐層 rebase 的小型 PR(即「Stacked PRs」)。它自動處理建立分支、維持 rebase 同步、設定正確的 PR base 分支,並在 GitHub 上把這些 PR 串連成一個可視化的 Stack,大幅降低手動管理堆疊分支的心智負擔。</p>
</section>
<section class="copy-section">
<h3>值得注意的亮點</h3>
<ul>
<li>由 GitHub 官方帳號(github/gh-stack)發布並維護,搭配 CODEOWNERS、SECURITY.md、Safe Harbor 政策等完整治理文件</li>
<li>指令涵蓋完整工作流:init/add/submit/sync/rebase/modify/merge/checkout,並提供互動式 TUI(用 bubbletea 打造)編輯 PR 標題與描述</li>
<li>modify 指令支援 drop/fold/insert/rename/reorder 等堆疊重構操作,並有清楚的前置條件與復原(undo/abort)機制</li>
<li>README 對每個指令、flag、exit code 都有詳盡說明,文件品質在 CLI 專案中屬上乘</li>
<li>可選安裝 AI agent skill(gh skill install github/gh-stack),讓 Copilot 等工具理解 stacked PR 工作流</li>
</ul>
</section>
<section class="copy-section">
<h3>適合誰使用</h3>
<ul>
<li>大型功能改動需要拆成多個循序漸進、易於審查的小型 PR</li>
<li>團隊採用 trunk-based development,需要頻繁 rebase 並保持多個相依分支同步</li>
<li>需要在 GitHub 介面上把多個 PR 視覺化串連成一個 review 鏈,方便 reviewer 逐層檢視差異</li>
</ul>
</section>
