<li>Desktop、TUI/CLI、Eval 三種介面共用同一個 Runtime Host 執行核心,權限與工具邏輯只實作一次</li>
<li>內建 Read/Write/Edit/Bash/Glob/Grep 等本地工具,搭配權限引擎與 watchdog,危險操作(檔案寫入、Shell)皆經過權限審核</li>
<li>憑證以 OS 帳號邊界隔離,採 POSIX 0700/0600 權限的本地明文 vault,renderer 進程不會拿到明文憑證</li>
<li>文件详实(架構文件、雙語深入解析、隱私與安全邊界文件齊全),CI 涵蓋 lint/typecheck/單元測試/E2E/sandbox smoke/發版驗證等多層檢查</li>
</ul>
</section>
<section class="copy-section">
<h3>適合誰使用</h3>
<ul>
<li>需要在本機安全地執行具檔案讀寫、Shell 執行等高風險工具呼叫的 AI Agent 工作流,且要求完整可稽核的執行紀錄</li>
<li>希望在同一套 Runtime 之上,同時支援 GUI 桌面應用、終端機 CLI、以及可重現的 Agent 評測(Eval)實驗</li>
