<h3>這是什麼</h3>
<p>Airgorah 是一套 Linux 專用的 WiFi 安全稽核軟體,提供 GTK4 圖形介面,可掃描附近 AP 與客戶端、執行 deauth 攻擊、擷取 handshake 與 PMKID,並搭配 aircrack-ng 破解密碼。專案採用 GUI(一般使用者)與特權 agent(經 polkit 提權)分離的架構,降低以 root 執行整個 GUI 的風險。</p>

<section class="copy-section">
<h3>值得注意的亮點</h3>
<ul>
<li>GUI 與特權 agent 分離:GUI 以一般使用者執行,需要提權時才透過 polkit/pkexec 啟動 airgorah-agent,同時相容 X11 與 Wayland</li>

<li>跨越特權邊界的參數(介面名稱、MAC、頻道過濾)在 agent 端重新驗證,降低命令注入風險</li>
<li>deauth 以原生 raw socket 在 Rust 內偽造 802.11 frame,並限制發送速率(1–1000 輪/秒)</li>
<li>提供 deb、rpm、pacman 打包,支援 x86_64 與 aarch64,CI 含 clippy 與 rustfmt 檢查</li>
</ul>
</section>
<section class="copy-section">
<h3>適合誰使用</h3>
<ul>
<li>在自己擁有或已獲授權的網路上做 WiFi 滲透測試與弱密碼稽核</li>
<li>資安教學與 CTF 中示範 WPA handshake / PMKID 擷取流程</li>
<li>研究 Rust 如何設計特權分離的 Linux 桌面安全工具</li>
