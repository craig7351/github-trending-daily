<h3>這是什麼</h3>
<p>Caveman 提供兩層方案:一個是免費的「skill」規則檔,讓 Claude Code / Codex / Gemini 等 30+ agent 用「穴居人式」精簡口吻回答,平均省下 65% 輸出 token;另一個是本地代理(proxy),攔截 agent 讀進來的 JSON/log/diff/搜尋結果等內容,依內容型態做安全分類的無損/可回溯壓縮,平均省下約 33% 輸入 token。核心賣點是「省錢但不犧牲正確性」,並提供可回溯機制(CCR store)保證原始內容隨時可取回。</p>
</section>
<section class="copy-section">
<h3>值得注意的亮點</h3>
<ul>
<li>採 fail-closed 設計:偵測不到型別、無法確認可回溯、壓縮後沒有變小,一律直接原樣放行,不會硬壓縮犧牲正確性</li>
<li>engine 目錄有數百個 *_test.go,含 adversarial probe 測試與跨平台(Windows/macOS/Linux)CI matrix,測試文化紮實</li>
<li>install.sh/install.js 明確 pin 到固定 release tag(非 main 分支),並在註解中解釋是為了修過去的安全事故(issue #249、#261)</li>
<li>誠實揭露效益上限:README 明講 65% 只算輸出 token,並附 docs/HONEST-NUMBERS.md 說明何時可能反而更貴</li>
<li>License 採 MIT(skill/CLI)+ BSL-1.1(engine/proxy)雙軌,四年後轉 Apache-2.0,商業自架收費模式寫得清楚</li>
</ul>
</section>
<section class="copy-section">
<h3>適合誰使用</h3>
<ul>
<li>用 Claude Code / Codex / Gemini CLI 等工具時想降低 API 帳單,尤其是輸出冗長解說的場景</li>
<li>agent 需要頻繁讀取大型 log、JSON、diff、搜尋結果時,想在丟給模型前先做內容感知壓縮</li>
