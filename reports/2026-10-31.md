<section class="copy-section">
<h3>這是什麼</h3>
<p>Lightpanda 不是 Chromium 或 WebKit 的分支,而是以 Zig 重新實作的瀏覽器,內嵌 V8 引擎。它提供 CDP 伺服器,Puppeteer 和 Playwright 可直接連線。它也有 fetch 模式,可把頁面轉成 HTML、Markdown 或結構化資料。官方 README 宣稱 100 頁爬取的尖峰記憶體約為 Chrome 的 1/16,執行時間約快 9 倍。這些數據來自官方基準測試,我沒有實際執行驗證。</p>
</section>
<section class="copy-section">
<h3>值得注意的亮點</h3>
<ul>
<li>以 Zig 從零實作,並非 Chromium 或 WebKit 分支,內嵌 V8 並以預建 snapshot 加速啟動</li>
<li>相容 CDP,可用 Puppeteer、Playwright 連線,並提供 serve 與 fetch 兩種模式</li>
<li>fetch 支援 --dump html、markdown、structured_data、png、pdf,適合餵給 LLM 或做爬蟲</li>
<li>程式碼內含 MCP 與 agent 相關模組,另有 Docker、Nix、Homebrew、AUR 等安裝方式</li>
<li>CI 完整,包含 zig-test、e2e、WPT(Web Platform Tests)、release 與 nix-build 等工作流程</li>
</ul>
</section>
<section class="copy-section">
<h3>適合誰使用</h3>
<ul>
<li>AI 代理的網頁瀏覽與擷取後端,取代較吃資源的 Headless Chrome</li>
<li>大規模爬蟲或網頁資料擷取,需要低記憶體與高併發</li>
<li>把網頁轉成 Markdown 或結構化資料,供 LLM 或 RAG 使用</li>
<li>在 CI 或容器中執行輕量的 Puppeteer、Playwright 自動化腳本</li>
</ul>
