<div class="repo-body">
<div class="repo-copy">
<section class="copy-section">
<h3>這是什麼</h3>
<p>Atlas 用 Tauri(Rust + TypeScript)打造,核心概念是「checkpoint」:每個 commit 都會連回產生它的 agent session,包含 prompt、工具呼叫與推理過程,方便事後查詢「哪個 agent 改了什麼、為什麼」。它也提供跨 agent 的共用記憶(on-device embedding + HNSW 語意搜尋),讓切換 Claude Code、Codex 或其他 ACP registry agent 時不用從零開始。專案本地優先,session 記錄預設存在本機 SQLite,帳號同步為選用功能。</p>
</section>
<section class="copy-section">
<h3>值得注意的亮點</h3>
<ul>
<li>Checkpoint 機制把 git commit 與產生它的 agent session(prompt/工具呼叫/推理)綁在一起,且能在 rebase/amend 後透過 patch-id 追蹤存活</li>
<li>支援多 agent 並行:Claude Code、Codex 走 ACP 協定作為子行程,自家 agent 用 Rust 框架 Cersei 原生執行,還能拉 ACP registry 裡的其他 agent(Cursor、OpenCode、Kilo Code)</li>
<li>TELEMETRY.md 罕見地詳盡揭露每個遙測事件、欄位與「絕不收集」清單,透明度在同類專案中相對突出</li>
<li>CI 涵蓋前端(lint/typecheck/build/vitest)與 19 個獨立 Rust crate 各自的 cargo test/clippy,加上 Tauri app 194 個測試,測試覆蓋面完整</li>
<li>程式碼與註解品質高,大量說明設計取捨與來源(例如明確標註『Ported from Zed』的邏輯來源與行號)</li>
</ul>
</section>
<section class="copy-section">
<h3>適合誰使用</h3>
<ul>
