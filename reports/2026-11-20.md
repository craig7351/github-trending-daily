<h3>這是什麼</h3>
<p>OpenSRE 是以 Python 撰寫的 CLI 代理。CI 失敗或告警觸發時,它會抓取 CI 日誌、近期 commit 與部署,以及相關的日誌、指標與追蹤,再以工具呼叫迴圈驗證假設,區分 CI 造成與程式碼造成的失敗。它可把修復推送到 PR 分支供人審核,並將摘要發到 Slack、PagerDuty 或 Telegram。專案宣稱整合 60 多種工具,支援 Anthropic、OpenAI、Ollama 等 LLM,目前為 public alpha。</p>
</section>
<section class="copy-section">
<h3>值得注意的亮點</h3>
<ul>
<li>整合面廣:Grafana、Datadog、CloudWatch、Kubernetes、GitHub/GitLab、PagerDuty、Slack 等 60 多種服務</li>
<li>支援多家 LLM 供應商(含 Ollama 本地模型),可自架,並可在送出外部 LLM 呼叫前選擇性遮罩敏感識別碼</li>
<li>提供互動式 REPL、headless CLI(opensre ask)與 Python 內嵌 API 三種使用方式</li>
<li>工程流程完整:多個 GitHub workflow、CodeQL、import 週期檢查、安裝程式 canary 測試</li>
<li>部署選項多元:託管 gateway、AWS AMI+systemd、Docker(Railway/ECS/Vercel)</li>
</ul>
</section>
