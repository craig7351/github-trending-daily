<section class="copy-section">
<h3>這是什麼</h3>
<p>Topcoat 是 Tokio 組織推出的模組化全端 Rust 框架,提供 `view!` 巨集模板、async 元件、模組式路由、資產打包、Tailwind 整合、Session/Cookie、Mail、OpenAPI、l10n 等功能。其特色是 `$(...)` 表達式:同一段型別檢查過的 Rust 程式碼在伺服器初次渲染,並轉譯成 JavaScript 於瀏覽器重跑,不需 wasm 或前端建置。README 明確標示為早期實驗性專案,API 可能出現破壞性變更。</p>
</section>
<section class="copy-section">
<h3>值得注意的亮點</h3>
<ul>
<li>`$(...)` 雙語表達式:同一段 Rust 同時在伺服器渲染並轉成 JS 在瀏覽器執行,免 wasm、免前端建置流程</li>
<li>`#[shard]` 元件在參數變動時由伺服器重新渲染並原地替換 HTML,async 元件可直接查詢資料庫</li>
<li>依模組結構自動推導路由(module_router),並提供 `topcoat fmt` 格式化巨集內容</li>
<li>Topcoat UI 仿 shadcn/ui,以 CLI 將元件複製進專案可自由修改;內建 Tailwind(免 Node)、字型與圖示打包</li>
<li>workspace 含約 40 個 crate、眾多範例與 benchmark(對比 Next.js、Leptos、axum-maud),並附 llms.txt 與 AGENTS.md 供 AI 代理使用</li>
</ul>
</section>
<section class="copy-section">
<h3>適合誰使用</h3>
<ul>
<li>想以純 Rust 開發伺服器渲染、帶局部互動的全端網站或後台管理系統</li>
<li>評估 Rust 全端框架(對比 Leptos、axum + maud)的技術選型與研究</li>
<li>研究 Rust 巨集 DSL、Rust 轉 JS 表達式編譯等框架設計</li>
<li>在 Cloudflare Worker 等 wasm 環境部署 Rust Web 應用的實驗</li>
</ul>
</section>
